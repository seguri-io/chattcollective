# Starving Dragon — UI Kit

**Source:** https://github.com/tritzriley/starvingdragon/blob/main/index.html

## What's Here
`index.html` — Full single-page website recreation. Interactive, scroll-based layout.

## Sections
1. **Nav** — sticky, blurred, with logo + links + Instagram handle
2. **Hero** — radial glow background, flame SVG placeholder logo, H1 + subtitle + CTA pair
3. **Origin / Story** — two-column: body copy + stat cards with left-border accent
4. **What Is Chili Crisp** — eyebrow + title + divider + 3-column card grid
5. **Sichuan Heritage** — feature list with icon squares
6. **Flavor Profile** — animated-ready horizontal bar chart
7. **Pairings** — 4-column card grid with emoji icons
8. **Ingredients** — 3-column grid with dot bullets
9. **Pull Quote** — centered italic Playfair quote
10. **Order** — CTA to Instagram
11. **Footer** — minimal two-column

## Key Design Tokens
- Background: `#0d0703` / `#110904`
- Accent: `#e8522a`
- Text: `#f5ede0` → warm ramp to `#705028`
- Display font: Playfair Display (700, 900, italic)
- Body font: Inter (300–600)
- Border radius: `2px` (nearly sharp)
- Borders: `1px solid rgba(200,80,20,0.12)`
