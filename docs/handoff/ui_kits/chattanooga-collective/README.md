# Chattanooga Collective — UI Kit

**Status:** Proposed / new brand (no existing site)

## What's Here
`index.html` — Full collective website: nav, hero, vendor cards, about, values, location, footer.

## Sections
1. **Nav** — parchment bg, leaf logo mark, links + "Shop Local" CTA
2. **Hero** — warm earthy background with radial green/ochre glows, Lora serif headings
3. **Vendors** — two-column vendor cards for Starving Dragon + Ridge and Valley
4. **About** — centered text section explaining the collective model
5. **Values** — 3-column grid: Real Ingredients / Local Craft / Community First
6. **Find Us** — two-column: body text + location placeholder map
7. **Footer** — dark wood background, logo + nav columns

## Key Design Tokens
- Background: `#f5f0e8` (parchment) / `#ede6d8` (section)
- Dark: `#2a2018`
- Primary green: `#3a5c3a`
- Ochre accent: `#c4831a`
- Text: `#1e1a14` → `#6a5438`
- Display font: Lora (400, 600, 700, italic)
- Body font: DM Sans (300–600)
- Border radius: `5–6px`

## Caveats
- Brand is *proposed* — colors, logo, typography not yet approved by stakeholders.
- Leaf mark logo is a conceptual placeholder SVG.
- Ridge and Valley card shows "Coming Soon" — no product details yet.
- No real e-commerce, pickup scheduling, or Instagram integration.
